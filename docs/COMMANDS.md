# QQ 指令

先在本机控制台生成配对码，再由对应 QQ 账号私聊机器人发送 `/pair 配对码`。绑定后可直接发送文字、图片、语音、视频或文件。

| 指令 | 用途 |
| --- | --- |
| `/help`、`/buttons` | 帮助与原生按钮菜单 |
| `/status`、`/context`、`/result` | 查看当前聊天任务、上下文和最近结果 |
| `/stop`、`/new` | 中断当前任务、开始新会话 |
| `/model`、`/models` | 查看当前模型或打开模型选择 |
| `/model 模型名 [推理强度]` | 保存本账号模型偏好，下次任务生效 |
| `/model default` | 恢复继承本账号 Codex 配置 |
| `/project 绝对路径` | 切换至本账号允许范围内的项目 |
| `/file 绝对路径`、`/send 绝对路径` | 回传本账号允许范围内的文件 |
| `/voice 文本`、`/media-test` | 生成语音、发送媒体测试素材 |
| `/memory`、`/remember 内容`、`/forget 编号` | 查看、保存或删除本账号私有记忆 |
| `/approve 编号`、`/deny 编号` | 回答审批 |
| `/answer 编号 回答` | 回答询问，多题用 `\|` 分隔 |

连续普通消息在停顿约 3 秒后合并，连续输入最长等待 10 秒；`/status`、审批和 `/stop` 即时处理。任务执行中补充内容会追加到当前轮，结束后再发的内容进入同一会话的下一轮。

模型与推理强度以本机 Codex 返回的可用列表为准；任务执行及结果发送期间不能切换。默认完成 40 轮或空闲 6 小时后，在下次任务开始时轮换会话，实际值以控制台配置为准。

任务阶段只记录引入该功能后的新任务。执行完成、QQ 投递与用户收件是不同状态；待核实的结果不会自动重跑或重发，见[任务状态说明](TASKS.md)。
